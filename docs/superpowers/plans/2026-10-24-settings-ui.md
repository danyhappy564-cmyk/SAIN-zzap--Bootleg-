## 제약과 결정

- 코드 수정·자동 검사·DLL 빌드는 사용자 승인입니다. 게임 재설치·게임/서버 실행·서버 API 호출은 아직 승인 범위에 포함되지 않습니다.
- Claude 작업 폴더와 원래 SAIN 체크아웃은 읽기만 합니다. E: 게임은 현재 진단용 읽기만 합니다.
- 전역 바닐라 > 봇별 AI 선택. 자리키·호위 저격수 및 기존 엄격 제외 역할은 항상 바닐라입니다. 잠긴 봇의 기존 SAIN 값은 보존합니다.
- 무선택 난이도 배지는 zzap 쉬움/보통/zzap의 해당 원본과 칸별로 비교합니다. 명시적으로 단계를 고르면 기존 계산을 사용합니다.
- 묶음 원본은 항상 [Modified] 복사본으로 저장하며, 편집 객체·캐시·서버 기본값 사이 참조를 분리합니다. 현재 서버 강제 프리셋은 null이므로 강제 예외가 이번 현상의 원인이라고 단정하지 않습니다.
- SAIN 원본 기본 프리셋은 사용자 선택 목록에서 제거합니다. 모드 봇 보충과 계산에 필요한 내부 기본 데이터는 유지합니다.
- 성격은 봇 하나당 한 번, 선택 후보 중 균등 무작위입니다. 1개 선택은 고정, 빈 목록은 자동 배정입니다. 기존 단일 지정도 읽으며 사용자가 바꾼 설정을 강제로 재설정하지 않습니다.
- 블랙 디비전 기본 후보는 Chad/GigaChad, Wedge(848424)는 GigaChad입니다. 기존 저장의 명시적인 지정은 보존하고 새 기본값과 원본 복원에 새 기본 후보를 사용합니다.
- 단계를 `쉬움 (zzap 쉬움 프리셋 수준)` 등 이름과 설명을 합친 형태로 표시합니다.

## 주요 실패 조건

- 저장 버튼을 눌렀다는 이유만으로 원본 JSON이나 다른 프리셋 객체가 바뀌지 않아야 합니다. 실패한 저장을 성공으로 표시하거나 dirty를 지우지 않습니다.
- 현재 바닐라인 봇이 SAIN 배지로 보이거나 일괄 변경에서 값이 바뀌지 않아야 합니다.
- 쉬움·보통 원본을 열기만 해도 직접 설정/변경됨이 되지 않아야 합니다.
- 성격 후보가 비어 있거나 모두 비활성이어도 정상 자동 배정으로 돌아가야 합니다. 후보 설정은 스냅샷/복원에서 깊게 복사해야 합니다.
- 1차 오프라인 시뮬은 전투 밸런스 변경 근거로 쓰지 않습니다(P16). 이번 수정에 불필요한 전투 로직·ORBIT은 수정하지 않습니다.
