## SAIN Remix7.3

**- 봇 설정 화면 개편: 여러 봇 한꺼번에 조절, 내 설정 슬롯, 공유 코드 (봇 행동·zzap 값은 Remix7.2 그대로)**

■ 바뀐 것
- 봇 목록에서 동그라미 또는 Ctrl+클릭으로 여러 봇을 묶어 난이도·손잡이·고급 값을 한꺼번에 조절 (묶음 밖 봇·전역 설정은 안 바뀜)
- 내 설정 슬롯(3~9칸)에 값을 담아 두고 다시 적용, 공유 코드로 친구와 주고받기 — F6와 웹이 같은 슬롯
- 새 항목만 보기·바뀐 항목만 보기, NEW 표시, 줄마다 '원래대로'
- 처음 여는 분용 3단계 안내 (오른쪽 위 ?로 다시 보기)
- F6·웹 화면 배치 통일, 영어 화면 몇 군데 수정
- 같이 써도 되는 모드 표에 PBT(Harmony Profiles)·Twitch Players 추가 (코드로 확인)

■ 설치
- SAIN.REMIX.7.3.7z 풀어서 SPT 폴더에 덮어쓰기 (클라이언트·서버 둘 다 바뀜, 설정 유지)
- 새로 깔 때는 [Modified] 붙은 프리셋과 ClientData/botSettingsSlots.json(슬롯)을 먼저 백업

■ 주의
- 슬롯 적용만으로는 저장 안 됨 — 위쪽 '저장'을 눌러야 게임에 반영
- '되돌리기' 뒤에도 '저장 안 한 변경' 개수가 안 줄어듦(전 판부터, 저장하면 정상)
