SAIN Remix7.4 — 설정 화면 정리: ZZAP 탭, 봇 종류별 전술 켜고 끄기, 봇 종류별 맵 보정

이번 판은 F6와 웹 설정 화면을 더 쉽게 정리하고, 봇 종류마다 전술과 맵별 수치를 따로 줄 수 있게 한 판입니다.
봇 행동(싸우는 방식)과 zzap 프리셋 값은 Remix7.3과 같습니다. 새 칸은 모두 '전역 따름', '1배'로 시작해서 업데이트만 해서는 아무것도 달라지지 않습니다.

[구분선]

■ 바뀐 것

1) 영어 화면에서 프리셋 이름도 영어로
- 영어 화면에서도 'zzap 쉬움', 'zzap 보통'처럼 한글로 보이던 기본 프리셋 이름을 'zzap Easy', 'zzap Normal', 'zzap TEST [sim only]'로 보이게 했습니다. 한국어 화면은 그대로입니다.
- 파일 이름은 그대로 두고 보이는 이름만 바꿨습니다. 그래서 이전에 골라 둔 프리셋과 [Modified] 사본이 그대로 이어집니다.

2) 비교 기준 순서, 내 프리셋 이름 바꾸기
- 비교 기준 버튼을 쉬움, 보통, zzap (어려움), 저장된 값 순서로 맞췄습니다(F6와 웹 같음).
- 직접 만든 프리셋 이름을 바꿀 수 있습니다. F6는 빠른 설정 왼쪽 아래 '이름 바꾸기' 버튼, 웹은 내 프리셋 카드의 연필 아이콘입니다. 게임이 그 프리셋을 쓰고 있으면 새 이름으로 따라갑니다. 기본 zzap 프리셋은 이름을 바꿀 수 없습니다.

3) 새 탭: 'ZZAP (전술 등..)', '시뮬레이션'
- 전역 설정에 섞여 있던 zzap 전술 묶음(문 전술, 정지 및 매복, 분대 교전, 근접 교전, 위치 변경, 플레이어 스타일 기록)은 'ZZAP (전술 등..)' 탭으로, 시뮬레이션 랩은 '시뮬레이션' 탭으로 옮겼습니다.
- ZZAP 탭은 '한눈에 켜고 끄기'부터 열립니다. 다이아몬드 스텝, QEQE 기울이기 사격, 모서리 흔들기 피킹, 탄 떨어지면 권총, 빠른 장전 같은 전술 14개를 쉬운 설명과 스위치로 켜고 끕니다. 세부 숫자는 왼쪽 묶음에 그대로 있습니다.

4) 봇 설정을 탭으로 나눔
- 한 화면에 몰려 있던 봇 종류별 설정을 빠른 설정, 성격, ZZAP, 맵별 보정, 고급 탭 5개로 나눴습니다(F6와 웹 같음).
- 성격 탭에서 그 봇 종류의 성격을 바로 정합니다.
- 고급은 묶음을 골라 한 묶음씩 볼 수 있고, 전에는 없던 'Zzap' 묶음도 생겼습니다.

5) 봇 종류마다 ZZAP 전술 따로
- 문 전술, 분대 교전, 위치 바꾸기, 근접전 zzap 행동 전체, 다이아몬드 스텝, QEQE 기울이기 사격, 모서리 흔들기 피킹을 봇 종류마다 '전역 따름', '켬', '끔'으로 고릅니다. 여러 봇을 묶어서 한 번에 바꿀 수도 있습니다.
- 켬은 전역 스위치와 '스캐브는 근접전 zzap 제외'보다 먼저 적용됩니다(예: 스캐브도 다이아몬드 스텝). 끔은 그 봇 종류만 그 전술을 안 씁니다(예: PMC만 QEQE 끄기).

6) 봇 종류마다 맵별 보정
- 제보 받은 요청("연구소에서는 봇이 소리를 덜 듣게, 리저브는 그대로")을 넣었습니다.
- 봇 종류마다, 맵마다 청각 거리, 시야 거리, 발견 속도, 공격성, 탄 퍼짐, 정밀 조준 속도, 조준 맞추는 시간을 배수로 줍니다. 1.0이 그대로입니다.
- 전역 '맵별 보정'(모든 봇 공통) 위에 곱해지고, 다음 레이드부터 적용됩니다. 바꾼 맵만 달라지고 다른 맵은 그대로입니다.
- 이번 판은 숫자 보정만 넣었습니다. '이 맵에서만 게임 기본 AI'는 AI를 바꾸려면 게임을 다시 켜야 해서 따로 검토합니다.

확인: 게임 F6와 크롬 웹 화면에서 한국어, 영어 둘 다 직접 눌러 봤고, 그때 찾은 작은 표시 문제 2개를 고쳤습니다. 시험 프리셋으로 리저브 레이드를 돌려 봇 값을 직접 읽어 보니, PMC에 'QEQE 끔, 근접전 끔'을 넣으면 실제로 근접전 zzap을 건너뛰었고, Usec에만 '리저브 청각 0.5배'를 넣으면 같은 판의 Usec은 0.5배, Bear는 1배였습니다. 그 판 게임 로그에 SAIN 오류는 없었습니다. 이전 판 프리셋은 전과 똑같이 동작하는 것을 자동 시험으로 확인했습니다.

■ 주의

- '되돌리기'를 눌러도 위쪽 '저장 안 한 변경' 개수가 줄지 않습니다(전 판부터 있던 것). 저장하면 정상으로 돌아옵니다.
- 서버를 처음 켤 때 기존 프리셋 파일에 새 칸이 붙어서 다시 저장됩니다. 값은 기본값이라 동작은 같습니다.
- 이상하면 Remix7.3 압축을 다시 덮어쓰면 원래대로 돌아갑니다.

■ 설치

SAIN.REMIX.7.4.7z 하나를 풀어서 SPT 폴더(EscapeFromTarkov.exe가 있는 곳)에 덮어쓰기. 클라이언트(BepInEx)와 서버 모드(SPT_Runtime)가 같이 들어 있고, 이번에는 둘 다 바뀌었습니다. 설정, 프리셋, 내 설정 슬롯은 그대로 유지됩니다.
지우고 새로 깔 때는 Presets 폴더 안의 [Modified] 붙은 파일과 직접 만든 프리셋, ClientData 폴더의 botSettingsSlots.json을 먼저 백업해 주세요.

■ 버그 제보

스크린샷 + BepInEx/LogOutput.log 같이 주시면 빨리 봅니다.
