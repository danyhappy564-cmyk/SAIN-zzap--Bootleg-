[SAIN-zzap--Bootleg-] remake5 올립니다 (Remix4.2 이후 변경)

Remix4.2 이후 약 1주일 동안 바뀐 걸 모았습니다. 코드 몰라도 알 수 있게 "게임에서 뭐가 달라지는지" 위주로 적었습니다.
이번 판은 대부분 **봇끼리 싸우게 돌려 보는 시뮬레이션**으로 확인했고, 사람 상대 체감은 아직 충분히 못 봤습니다. 이상하면 알려 주세요.

---

■ 설치

- Remix4.2 / remake4 쓰던 분: **클라이언트 SAIN.dll + 서버 모드 둘 다 덮어쓰기** (이번엔 서버 모드도 바뀜)
  - 서버 모드 `Presets` 폴더의 zzap 프리셋도 덮어써 주세요. 기본 `zzap` 프리셋 값은 그대로입니다.
- 그보다 옛날 버전 / 원본 SAIN 쓰던 분: remake4 글의 설치 순서대로

■ 이번에 새로 생긴 것

1. **싸우면서 피킹합니다**
   예전엔 코너에서 좌우로 살짝 흔드는 게 전부였는데, 이제 교전 중에 숨었다 나왔다 하며 쏩니다.
   - 옆걸음 피킹(가장 흔함) / 옆으로 점프해서 확인 후 착지해서 쏘기 / 트인 곳을 반대편 엄폐까지 뛰어 건너기
   - 점프·뛰어 건너기는 공격적인 봇(Chad·GigaChad, 일반 PMC 절반)만 합니다.

2. **분대가 역할을 나눠서 싸웁니다**
   분대원 2명 이상이 숨어 있는 적 하나를 상대하면, 1명은 옆으로 돌아가고 나머지는 그 자리에서 견제 사격, 3명 이상이면 1명은 뒤를 봅니다.
   돌아가는 아군이 사격 방향에 들어오면 쏘는 걸 멈춥니다(아군 오사 방지).

3. **봇끼리도 발소리를 듣습니다**
   원래 SAIN은 봇끼리 발소리를 못 들어서, 서로 보이거나 총을 쏴야만 알아챘습니다.

4. **빈틈을 노립니다**
   적이 장전·치료·수술·루팅하는 소리를 들으면, 그 사이에 닿을 수 있을 때만 달려듭니다. 수류탄 핀 소리를 들으면 물러납니다.

5. **조용히 다가옵니다**
   안 보이는 적에게 다가갈 때 가까워지면 걷고, 더 가까우면 숙여 걷습니다.

6. **먼 총소리엔 덜 반응합니다**
   가까운 총소리는 확인하러 가고, 먼 총소리는 고개만 돌리고, 아주 먼 건 무시합니다. 나를 쏜 사람은 거리 상관없이 반응.

7. **위·아래층 발소리는 작게 들립니다** (실내)

8. **벽 보고 멍하니 서 있지 않습니다** — 적이 나올 코너를 봅니다.

■ 바뀐 것

- **"얼음 매복" → "정지 및 매복"** 으로 이름 변경. 먼 적에겐 덜 매복하고, 다른 적에게 노출된 자리에선 안 합니다.
- **움직일 때 조준을 풉니다** — 예전엔 조준한 채 느릿느릿 걷다 맞아 죽는 일이 많았습니다. 맞는 중이면 바로 엄폐로 뜁니다.
- **문 앞에서 느리게 걷던 것 줄임** — 급할 땐 열린 문은 신경 안 씁니다.
- **도망칠 때 점프** — 뛰자마자 짧게 뛰던 것 없애고, 속도 붙은 뒤에 멀리 뜁니다.
- **판단이 왔다 갔다 하던 것 줄임** — 적이 잠깐 가려질 때마다 행동이 바뀌던 것.
- **총구가 좌우로 흔들리던 것 줄임** — 적이 잠깐 가려져도 마지막 위치를 계속 봅니다.
- **돌격하면서 치료하지 않음**
- **하늘 쳐다보던 것 고침**
- 일반 성격 PMC도 문 피킹을 하고, 다른 층 문을 고르던 것 고침
