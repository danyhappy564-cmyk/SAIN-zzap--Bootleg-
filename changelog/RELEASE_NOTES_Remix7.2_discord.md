## SAIN Remix7.2

**- 레이드가 끝난 뒤 메뉴에서도 지난 레이드 메모리를 붙잡고 있던 것 수정 (봇 행동·설정·zzap 값은 Remix7.1 그대로)**

■ 바뀐 것
- 레이드 끝나고 메뉴로 와도 지난 레이드의 맵·봇 정보가 메모리에 남아 있던 것 수정 — RAM 클리너 누수 보고에서 SAIN이 맨 위로 나오던 원인 (게임 시뮬 3판에서 누수 목록에서 사라진 것 확인)
- 정리가 늦게 돌 때 새 레이드 봇의 소리 듣기까지 끊을 수 있던 것도 같이 수정
- 지난 판 주의 사항(문짝 장치 켜면 멈칫 증가?)을 같은 조건으로 비교: 차이는 봇이 처음 나온 직후 0.08초 멈칫 2번뿐, 평균 프레임 같음 → 기본값 켬 유지

■ 설치
- 클라이언트 + 서버 모드 둘 다 덮어쓰기 (서버는 버전 이름만 바뀜, 설정 유지)
- 새로 깔 때는 [Modified] 붙은 프리셋 파일을 먼저 백업

■ 주의
- 봇이 처음 나올 때 한 번 있는 약 0.3초 멈칫은 문짝 설정과 상관없이 있습니다(조사 중)
