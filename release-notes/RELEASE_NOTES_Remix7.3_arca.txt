[대표 이미지]

SAIN Remix7.3 — 봇 설정 화면 개편: 여러 봇 한꺼번에 조절, 내 설정 슬롯, 공유 코드

이번 판은 F6와 웹의 봇 종류별 설정 화면을 손본 판입니다.
봇 행동(싸우는 방식)과 zzap 프리셋 값은 Remix7.2와 같습니다.

[구분선]

■ 바뀐 것

1) 봇 여러 종을 묶어서 한꺼번에 설정
- 전에는: 봇 종류를 하나씩 열어서 같은 값을 여러 번 바꿔야 했습니다.
- 이제: 왼쪽 봇 목록에서 이름 옆 동그라미를 누르거나 이름을 Ctrl+클릭하면 묶음에 들어갑니다. 팩션 줄의 동그라미는 그 팩션 전체를 고릅니다. 이름만 누르면 묶음은 그대로 두고 그 봇 하나를 봅니다.
- 묶음 상태에서 난이도, 손잡이 9개, 고급 값을 바꾸면 고른 봇 모두에 같은 값이 들어갑니다. 고른 봇끼리 값이 서로 다르면 '섞임'이라고 표시됩니다.
- 묶음에 안 넣은 봇과 전역 설정은 안 바뀝니다. 게임 기본 AI(바닐라)로 고정된 봇은 알아서 건너뜁니다.

2) 내 설정 슬롯과 공유 코드
- '＋ 지금 값 저장'을 누르면 지금 보고 있는 봇의 값을 슬롯에 담아 둡니다. 처음 3칸이고 최대 9칸까지 늘어납니다. 슬롯 이름을 누르면 지금 봇이나 묶음 전체에 그 값이 들어갑니다.
- 슬롯 옆 [...] 메뉴에서 이름 바꾸기, 덮어쓰기, 삭제, 공유 코드 복사를 할 수 있습니다. 친구가 준 코드는 '공유 코드 붙여넣기'로 넣으면 새 슬롯이 됩니다. 코드에는 슬롯 이름, 난이도, AI, 바꾼 값만 들어갑니다.
- 슬롯은 프리셋과 따로 저장돼서 프리셋을 바꿔도 남아 있고, F6와 웹이 같은 슬롯을 씁니다.
- 주의: 슬롯에 담거나 적용하는 것만으로는 프리셋이 저장되지 않습니다. 게임에 쓰려면 위쪽 '저장'을 눌러 주세요.

3) 새 항목만 보기, 바뀐 항목만 보기, 항목별 원래대로
- 고급 설정과 '전역 설정' 탭에 '새 항목만 보기', '바뀐 항목만 보기'가 생겼습니다. 최근에 새로 생긴 설정에는 NEW 표시가 붙습니다(지금은 '봇이 열린 문짝을 돌아서 지나감').
- 원래 값과 다른 줄에는 노란 점이 붙고, 줄마다 '원래대로' 버튼으로 그 봇의 원래 값으로 되돌릴 수 있습니다(전에는 '기본값' 버튼).

4) 처음 여는 분을 위한 3단계 안내
- 봇 설정을 처음 열면 노란 안내 띠가 나오고 '3단계 안내'(봇 고르기, 난이도와 손잡이, 저장과 슬롯과 공유)를 볼 수 있습니다. '알겠어요'를 누르면 다시 안 나오고, 오른쪽 위 '?'로 언제든 다시 볼 수 있습니다.

5) 화면 정리
- F6와 웹 화면 배치를 똑같이 맞췄습니다. 위쪽에 '저장 안 한 변경 N개, 저장, ?', 단계 번호(01 난이도 고르기, 02 손잡이, 03 고급), 웹의 팩션 순서도 F6와 같게 했습니다.
- 탭 이름 '전역 설정 (전체)'를 '전역 설정'으로 줄였고, 웹 탭의 NEW 표시가 'N'만 보이던 것도 고쳤습니다.
- 영어 화면에서 한국어 번역 모드를 같이 쓰면 고급 설정 버튼이 '[꺼짐]'으로 보이던 것, 1개일 때 복수형으로 나오던 것도 고쳤습니다.
- 업데이트한 뒤 브라우저가 예전 웹 화면 모양을 계속 보여 주던 것을 막았습니다.

6) 같이 써도 되는 모드 표 (깃허브 설명 페이지)
- 게임이나 코드로 확인한 모드만 버전과 함께 정리했습니다.
- Harmony Profiles (PBT) 1.0.0: 코드로 확인. PMC 이름, 레벨, 장비, 전적만 다루고 봇 AI는 건드리지 않습니다. PBT의 성격은 전적과 채팅용이라 SAIN 전투 성격과는 따로 놉니다.
- Twitch Players 3.1.2: 코드로 확인(Bot Callsigns 필요). 방송인 이름 봇에 원래 성격이 그대로 들어가고, 같이 오는 Twitch Players 프리셋도 zzap에서 열립니다. F6에서 PMC '성격 지정'을 직접 정하면 그 값이 먼저입니다.

확인: 게임 F6와 크롬 웹 화면에서 한국어, 영어 둘 다 직접 눌러 봤습니다(묶음 고르기, 슬롯 저장, 적용, 이름 바꾸기, 삭제, 공유 코드 주고받기, 필터, 안내). 실제 프리셋 저장은 자동 시험으로 확인했습니다. 슬롯 값을 넣고 레이드에서 봇이 그대로 싸우는지는 아직 따로 보지 않았습니다. PBT와 Twitch Players는 코드로만 확인했습니다.

■ 주의

- '되돌리기'를 눌러도 위쪽 '저장 안 한 변경' 개수가 줄지 않습니다(전 판부터 있던 것). 저장하면 정상으로 돌아옵니다.
- AI(SAIN, 게임 기본) 변경은 게임을 다시 켜야 적용됩니다.
- 이상하면 Remix7.2 압축을 다시 덮어쓰면 원래대로 돌아갑니다(슬롯 파일은 남아 있어도 괜찮습니다).

■ 설치

SAIN.REMIX.7.3.7z 하나를 풀어서 SPT 폴더(EscapeFromTarkov.exe가 있는 곳)에 덮어쓰기. 클라이언트(BepInEx)와 서버 모드(SPT_Runtime)가 같이 들어 있고, 이번에는 둘 다 바뀌었습니다. 설정과 프리셋은 그대로 유지됩니다.
지우고 새로 깔 때는 Presets 폴더 안의 [Modified] 붙은 파일과 직접 만든 프리셋, 그리고 슬롯을 남기려면 ClientData 폴더의 botSettingsSlots.json을 먼저 백업해 주세요.

■ 버그 제보

스크린샷 + BepInEx/LogOutput.log 같이 주시면 빨리 봅니다.
