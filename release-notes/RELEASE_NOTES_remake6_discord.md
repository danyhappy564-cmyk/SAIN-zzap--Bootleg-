## SAIN V remake6

**- 게임 안 F6 설정 창과 서버 웹 화면을 새로 만들었습니다 (봇 행동은 Remix5.1과 같음)**

■ 바뀐 것
- F6 첫 탭 "빠른 설정": 프리셋 카드(누르면 바로 바뀜), 저사양 PC 스위치 하나, 자주 바꾸는 값 14개 (게임 확인)
- 각 값에 "zzap 3배 → 2.25배 ▼ 약하게 · 25% 느림" 표시와 빨강(어려워짐)/초록(쉬워짐) 차이 막대, 비교 기준 선택 가능 (게임 확인)
- 전역 설정·봇 종류별·성격·장비 은밀성 탭도 왼쪽 목록 + 오른쪽 값으로 정리, 저장 버튼은 위쪽 하나 (게임 확인)
- 저장 안 한 값이 프리셋을 바꿔도 남던 문제 → 저장/버리기/취소를 물음 (미확인)
- 웹 프리셋 화면: 빠른 설정·프리셋 비교·바꾼 값 탭 (웹 확인), 시뮬·분석·업데이트 페이지 개편 (미확인)
- 프리셋 "보통"을 쉬움과 zzap의 중간으로: 반동 절반, 조준 1초→0.6초, 보는 거리 1.4배 (체감 미확인)
- zzap 프리셋을 고쳐 저장하면 "[Modified]" 복사본이 생겨 업데이트해도 안 날아감 (미확인)

■ 설치
- 클라이언트 SAIN.dll + 서버 모드 둘 다 덮어쓰기, 서버 모드 zip의 wwwroot 폴더도 같이 (웹 디자인 파일, 예전 zip엔 빠져 있었음)
- 서버 모드 Presets의 zzap 프리셋도 덮어쓰기

■ 주의
- 예전에 zzap 프리셋을 직접 고쳐 저장했다면 덮어쓰기 전에 그 파일을 다른 이름으로 복사해 두세요
- 화면이 이상하면 스크린샷과 LogOutput.log 부탁드립니다
