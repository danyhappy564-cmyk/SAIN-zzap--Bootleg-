## SAIN V Remix5.1

**- 봇이 달려서 문을 박차 열고, 문 끼임·어설픈 동작을 고쳤습니다**

■ 바뀐 것
- 봇 몸통박치기: 돌입·도망·돌격·수색 중 닫힌 문을 달려서 박차 엶. 안 터지면 걷어참. 다른 박치기 모드 필요 없음 (시뮬 확인)
- 문 끼임: 반대로 열린 문짝은 밀어서 되돌림, 손으로 여는 문도 밀어서, 연구소 유리문은 다 열릴 때까지 기다림 (미확인)
- 총을 계속 바꾸던 것(무기 핑퐁) 세 가지 경우 수정 (미확인)
- 위층의 안 보이는 적에게 천장·벽 사격 안 함 (시뮬 확인)
- 코앞을 지나가는 적에게 늦게 반응하던 것, 적도 안 보이는데 뒷걸음질, 자기 수류탄에 죽음, 트인 곳에서 치료 수정 (미확인)
- F8: 레이드 일지를 켜고 이상한 장면에서 누르면 그 순간 봇 상태가 일지에 남음 — 제보 때 스크린샷과 같이 주세요

■ 설치
- 클라이언트 SAIN.dll + 서버 모드 둘 다 덮어쓰기, 서버 모드 Presets의 zzap 프리셋도 덮어쓰기

■ 주의
- 대부분 시뮬로만 확인했습니다. 박치기가 싫으면 F6 → General → Door Tactics (zzap) → Bot Sprint Ram 끄기
