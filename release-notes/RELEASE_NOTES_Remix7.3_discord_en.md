## SAIN Remix7.3

**- Bot settings overhaul: edit several bots at once, custom slots, share codes (bot behaviour and zzap values same as Remix7.2)**

■ What's new
- Pick several bot types with the circle or Ctrl+click and change Level, knobs and advanced values for all of them at once (bots outside the selection and global settings stay as they are)
- Custom slots (3 to 9): keep values, apply them again later, and trade them with friends as share codes. F6 and the web page share the same slots
- New only / Changed only filters, NEW badges, and a Reset button on every row
- 3-step guide for first-time users (open it again with ? at the top right)
- F6 and web page now share one layout; a few English screen fixes
- Compatible mods table now lists PBT (Harmony Profiles) and Twitch Players (checked by code)

■ Install
- Extract SAIN.REMIX.7.3.7z into your SPT folder and overwrite (client and server both changed, settings kept)
- On a clean install, back up your [Modified] presets and ClientData/botSettingsSlots.json (your slots) first

■ Notes
- Applying a slot does not save the preset. Press Save at the top to use it in game
- Undo does not lower the "unsaved changes" count (since the last release; saving clears it)
