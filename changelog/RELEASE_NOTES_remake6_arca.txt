SAIN 포팅판 remake6 — 게임 안 F6 설정 창과 서버 웹 화면을 새로 만들었습니다

이번 판은 봇이 싸우는 방식은 Remix5.1과 같고, 설정하는 화면을 전부 새로 만든 판입니다.
봇 값이 바뀐 건 프리셋 '보통' 하나뿐입니다.
F6 화면은 보내 주신 게임 스크린샷을 보며 두 번 고쳤습니다. 마지막에 고친 몇 가지는 아직 게임에서 확인하지 못해서 따로 적었습니다.

[구분선]

■ 바뀐 것

1) 게임 안 F6 설정 창을 새로 만들었습니다
- 전에는: 빨간 막대가 줄줄이 이어진 긴 목록이라, 무엇을 어디서 바꾸는지 찾기 어려웠습니다.
- 이제 첫 탭 "빠른 설정":
  왼쪽에 zzap 프리셋 카드가 있습니다. 난이도가 막대 세 칸으로 보이고, 누르면 바로 그 프리셋으로 바뀝니다.
  오른쪽 위 "저사양 PC" 스위치 하나로 프레임을 잡아먹는 계산 다섯 가지를 한 번에 켜고 끕니다. 쉬움·보통·zzap 어느 난이도에나 켤 수 있습니다.
  그 아래에 자주 바꾸는 값 14개(반동, 조준 시간, 연사 속도, 탄 퍼짐, 시야 거리, 발견 속도, 청각, 시야각, 문 전술, 문 박치기, 코너 미리 쏘기, 분대 돌격, 레이드 일지, 진단 기록)가 있습니다.
- 숫자를 알아보기 쉽게:
  슬라이더는 모두 오른쪽으로 갈수록 봇이 강해집니다.
  각 줄 위에 "zzap 3배 → 2.25배 ▼ 약하게 · 25% 느림"처럼 비교 기준과 지금 값이 나옵니다.
  슬라이더에는 기준(노란 선)과 지금 값 사이가 빨강(봇이 강해짐 = 어려워짐) 또는 초록(약해짐 = 쉬워짐)으로 칠해져서 얼마나 바뀌었는지 한눈에 보입니다.
  비교 기준은 zzap / 쉬움 / 보통 / 저장된 값 중에 고를 수 있고, "저장된 값"을 고르면 방금 바꾼 것만 보입니다.
  아래 설명 글은 SAIN 기본값을 기준으로 씁니다. 예: "SAIN 기본보다 2.25배 빨리 방아쇠를 당김 (zzap 3배)". "zzap과 같음"만 나오면 zzap 값을 따로 알아야 한다는 의견을 반영했습니다.
- 나머지 탭:
  전역 설정은 왼쪽에 검색칸과 묶음 목록, 오른쪽에 고른 묶음만 나옵니다.
  봇 종류별은 봇 종류·난이도 / 설정 묶음 / 값 세 칸입니다. 전에는 펼치는 버튼을 여러 번 눌러야 값이 나왔습니다.
  성격과 장비 은밀성은 왼쪽 목록, 오른쪽 값입니다.
  켬/끔은 스위치로 나오고, 기본값과 다를 때만 "초기화" 버튼이 나옵니다. 저장 버튼은 위쪽 노란 버튼 하나로 합쳤고, 옆에 "저장 안 한 변경 N개"가 표시됩니다. 한국어/영어 전환도 됩니다.
- 창 왼쪽 위에 이제 릴리즈 이름(remake6)이 나옵니다. 전에는 SAIN 내부 번호(4.5.1)가 나와서 헷갈렸습니다. 내부 번호는 프리셋이 깨지지 않게 그대로 둡니다.
- 확인: 새 모양과 차이 표시는 게임 스크린샷으로 확인했습니다. 설정 이름이 두 줄로 접혀 잘리던 것을 마지막에 고쳤는데, 이건 아직 게임에서 확인 못 했습니다.

2) 저장 안 한 값이 프리셋을 바꿔도 남아 있던 문제 (아직 게임에서 확인 못 함)
- 언제: F6에서 값을 움직이고 저장하지 않은 채 다른 프리셋을 골랐다가 다시 돌아오면
- 왜: 설정 창이 불러온 프리셋을 메모리에서 바로 고치는데, 다른 프리셋을 고를 때 "저장 안 함" 표시만 지우고 바뀐 값은 그대로 두었습니다. 그래서 다시 고르면 바꾼 값이 저장된 값처럼 보였습니다.
- 이제: 저장 안 한 변경이 있을 때 다른 프리셋을 누르면 "저장하고 바꾸기 / 버리고 바꾸기 / 취소"를 묻습니다. 버리면 정말 저장된 값으로 돌아갑니다.

3) 서버 웹 화면도 새로 만들었습니다
- 프리셋 화면: 카드 목록에 탭 네 가지가 생겼습니다.
  "빠른 설정"은 F6과 같은 14개 값에 저사양 PC 스위치와 비교 색 막대가 있습니다.
  "프리셋 비교"는 zzap 프리셋끼리 값을 나란히 보여 줍니다.
  "바꾼 값"은 바꾼 것만 모아 보여 주고, 줄마다 되돌릴 수 있습니다.
  나머지 하나는 예전처럼 전체 설정입니다.
  새 프리셋을 만들 때 zzap 프리셋을 바탕으로 고를 수 있습니다.
- 전에는 웹이 zzap 프리셋을 제대로 못 찾아서 비교 칸이 비어 있었는데, 그것도 고쳤습니다.
- 시뮬레이션 페이지와 분석 페이지: 한눈에 보는 요약 숫자, 카드, 표 위주로 정리했습니다.
- 업데이트 페이지: 원본 SAIN 대신 이 포크의 릴리즈 기록을 보여 주고, 지금 쓰는 판과 새 판 알림이 나옵니다.
- 웹 화면 디자인 파일이 서버 모드 압축 파일에 빠져 있었습니다. 그래서 압축 파일로 설치하신 분은 웹 화면이 꾸밈 없이 보였을 수 있습니다. 이번 압축 파일에는 들어 있습니다.
- 확인: 프리셋 화면은 웹 스크린샷으로 확인했습니다. 시뮬·분석 페이지는 아직 확인 못 했습니다.

4) 프리셋 "보통"을 쉬움과 zzap의 진짜 중간으로 바꿨습니다
- 전에는: 원본 SAIN의 "보통" 값을 따라서 zzap과 너무 차이가 났습니다. 반동이 zzap의 16배, 조준 1초, 보는 거리도 SAIN 기본과 같았습니다.
- 이제: 반동이 절반(zzap의 8배)으로, 조준은 1초에서 0.6초로, 보는 거리는 SAIN 기본의 1.4배로, 연사는 zzap의 60%에서 75%로 바뀌었습니다. 적을 알아채는 속도와 소리 듣는 거리는 75%에서 85%로, 좌우로 보는 범위는 150도에서 160도로 바뀌었고, 실수도 조금 줄였습니다. 문 전술 같은 전술 빈도는 그대로입니다.
- "저사양 [테스트]" 프리셋도 "보통 + 성능 설정"이라 같이 바뀌었습니다. 이제는 아무 프리셋에서나 빠른 설정의 "저사양 PC" 스위치로 같은 효과를 낼 수 있습니다.
- 확인: 게임 체감은 아직 확인 못 했습니다. 예전 보통이 더 좋으면 F6 빠른 설정에서 반동·조준 시간 슬라이더를 왼쪽으로 옮기면 됩니다.

5) zzap 프리셋을 고쳐 저장하면 복사본이 생깁니다 (아직 게임에서 확인 못 함)
- 전에는: zzap 프리셋을 고쳐 저장하면 그 파일에 바로 덮어써서, 모드를 업데이트하면 고친 값이 날아갔습니다.
- 이제: "이름 [Modified]" 복사본으로 저장되고 원본은 그대로 남습니다. F6에서는 저장하자마자 그 복사본으로 바뀝니다.
- 서버 설정에서 프리셋을 강제로 고정해 둔 경우만 예전처럼 원본에 저장합니다.

6) 기타
- 도움말의 "얼음 매복" 표기를 "정지 및 매복"으로 통일했습니다.
- 디클러터, CompoundingPerf, 램클리너와 같이 써도 서로 같은 곳을 건드리지 않는 것을 확인했습니다.

혹시 이상하면: 화면 스크린샷을 보내 주세요. 새 설정 창이 불편하면 Remix5.1의 클라이언트 파일로 되돌리면 예전 창으로 돌아갑니다(봇 행동은 같습니다).

■ 설치

- Remix5.1에서 올라오면 클라이언트 SAIN.dll과 서버 모드를 둘 다 덮어써 주세요.
- 서버 모드 압축 파일 안의 wwwroot 폴더(웹 화면 디자인)도 같이 풀어 주세요.
- 서버 모드 Presets 폴더의 zzap 프리셋도 덮어써 주세요("보통"이 바뀌었습니다).
- 예전에 zzap 프리셋을 직접 고쳐 저장하셨다면, 덮어쓰기 전에 그 프리셋 파일을 다른 이름으로 복사해 두세요. 예전 판은 원본에 바로 저장해서 업데이트하면 원래 값으로 돌아갑니다.

■ 버그 제보
