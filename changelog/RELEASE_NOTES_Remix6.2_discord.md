## SAIN V Remix6.2

**- 블랙 디비전·RUAF·UNTAR 봇도 SAIN으로 싸움 (원래 봇 행동은 Remix6.1 그대로)**

■ 바뀐 것
- 모드 봇이 게임 기본 AI로 싸우던 것 → 봇이 나올 때 기본 전투 판단을 다시 빼서 SAIN이 싸움 (게임 확인: 블랙 디비전 0% → 67%)
- 블랙 디비전 포크 없이 원본 모드 그대로 사용
- 모르는 적에게 맞으면 알아채고 반격 (모드 봇)
- F6 봇 종류별 "성격 지정 (모드 봇용)" — 블랙 디비전 기본 GigaChad
- 레이드가 끝나면 지난 판 플레이어·봇 목록 비움
- 시뮬 프리셋 "모드 봇 SAIN 점검" 추가

■ 설치
- 클라이언트(SAIN.dll, SAIN.Preset.Shared.dll) + 서버 모드 둘 다 덮어쓰기
- 블랙 디비전 zzap 포크판을 쓰던 분은 원본 모드로 교체

■ 주의
- 모드 봇은 모드가 주는 약이 적어서 치료를 거의 못 함 (SAIN과 무관)
- 이상하면 스크린샷 + LogOutput.log 부탁드립니다
