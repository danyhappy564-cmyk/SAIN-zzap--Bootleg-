## SAIN V Remake7

**- 설정 화면 대개편: 봇마다 난이도·AI 고르기, 모드 봇도 SAIN으로 싸움 (원래 봇 전투 방식·zzap 값은 그대로)**

■ 바뀐 것
- 봇 종류별 설정: 봇 하나씩 보기, 난이도 고르기(zzap 쉬움·보통·zzap 수준·더 세게), 쉬운 손잡이 9개, 되돌리기·원본 사용·다른 봇에 복사
- 봇마다 AI 고르기: SAIN / 게임 기본 (게임 재시작 후 적용)
- 성격 후보: 모든 봇에서 여러 개 고르기 가능 (블랙 디비전 기본 Chad·GigaChad)
- 전역·성격·장비 설정에 프리셋 비교 막대, "기본값으로" 버튼, 접기 화살표
- 기본 zzap 프리셋은 읽기 전용, 고치면 [Modified] 복사본으로 저장 (저장이 엉뚱하게 되던 오류 여러 개 수정)
- zzap 저사양 프리셋 삭제 → "빠른 설정 › 저사양 PC" 스위치로 대신
- 블랙 디비전·RUAF·UNTAR 봇이 SAIN으로 싸움 (게임 확인: 블랙 디비전 0% → 67%), 포크 없이 원본 모드 그대로
- 레이드가 끝나면 지난 판 플레이어·봇 목록 비움

■ 설치
- 클라이언트(SAIN.dll, SAIN.Preset.Shared.dll) + 서버 모드 둘 다 덮어쓰기
- 새로 깔 때는 [Modified] 붙은 프리셋 파일을 먼저 백업
- 블랙 디비전 zzap 포크판을 쓰던 분은 원본 모드로 교체

■ 주의
- 새 설정 화면은 게임·웹에서 직접 눌러 본 확인 전입니다. 이상하면 스크린샷 + LogOutput.log 부탁드립니다
