## SAIN V Remix6.1

**- 봇이 싸우는 방식의 버그 수정·조정 (remake6 화면 그대로)**

■ 바뀐 것
- 레이저·손전등이 켜진 채 남던 것 → 총의 장비 전부 한 번에 켜고 끔, 권총집 총도 끔 (미확인)
- 제자리에서 위로만 뛰던 점프 → 움직이는 중에만 뜀 (게임 확인)
- 매복이 몇 분씩 이어지던 것 → 같은 적은 40초까지만 (게임 확인)
- 싸움 뒤 멍하니 서 있기 → 소리만 들은 적도 조용하면 찾으러 감, 뒤진 자리 적은 잊음 (일부 남음)
- 적이 근처에 있는데 치료 → 발소리·가까운 적 있으면 미루거나 취소 (체감 미확인)
- 다리가 부서진 봇 → 싸움 중에도 엄폐에서 성격별 확률로 수술, 바로 취소되던 버그 수정 (미확인)
- 권총↔주무기 핑퐁 → 적이 보이고 30m 안일 때만 권총 (미확인)
- 원래 SAIN 버그 5개(토끼뜀 설정 무시, 성격 확률 100% 넘김 등), 늘 100%이던 행동 90%로

■ 설치
- 클라이언트 SAIN.dll + 서버 모드 둘 다 덮어쓰기
- 서버 모드 Presets의 zzap 프리셋 5개도 덮어쓰기 ([Modified] 복사본은 남음)

■ 주의
- 마지막 4가지(수술·핑퐁·치료 점수·시뮬 시체)는 아직 게임 미확인
- 이상하면 스크린샷 + LogOutput.log 부탁드립니다
